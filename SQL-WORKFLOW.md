# SQL-файлы и Clutch

1. Откройте `.sql` и нажмите правую кнопку → **Работать через Clutch…**.
   Такой же пункт есть в **Работа → SQL**.
2. Выберите подключение Clutch. Файл остаётся в своём буфере; отдельная
   консоль не создаётся. Запросы при подключении не выполняются.
3. В Clutch-меню есть статус **Clutch: не подключён** или имя подключения.
   Если выбор был отменён, используйте **Подключить этот файл…**.
4. После подключения доступны **Выполнить выделение** и **Выполнить весь SQL**.
   Результаты показывает штатный Clutch: ниже исходного окна, повторно
   используя уже открытое окно результатов.
5. **Сменить подключение…** и **Отключиться** используют штатное управление
   сессией Clutch, включая его подтверждения при закрытии сессии/транзакции.
6. **Вернуться в обычный SQL-режим** сначала отключает Clutch, затем меняет режим.
   iSQL доступен в обычном SQL-режиме через явный пункт **Открыть iSQL…**.

Переключение сохраняет текст, положение курсора, выделение, кодировку и
признак несохранённых изменений. Оно не сохраняет файл автоматически.
Отмена подключения оставляет файл в Clutch без соединения.

В исходном Clutch остаются его встроенные меню/команды для отдельных консолей.
Для работы в файле используйте описанные выше пункты контекстного меню или
**Работа → SQL**. Ранее открытые iSQL-буферы автоматически не закрываются.

Новые команды также доступны через M-x: `my/sql-use-clutch`,
`my/clutch-connect-file`, `my/sql-use-standard-mode`.

Изменены только `lisp/init-sql.el` и `lisp/init-workspace-menu.el`.
Для отката восстановите их копии из `backups/clutch-file-flow-*` и перезапустите
Emacs. Существующие подключения при откате следует закрыть штатно заранее.
