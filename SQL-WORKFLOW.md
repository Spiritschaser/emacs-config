# SQL в Emacs

## Рабочее пространство Clutch

- **PostgreSQL.** Выберите сохранённое подключение в **Работа → Clutch** или вызовите `M-x my/clutch-workspace-open` и выберите его в минибуфере.
- **SQLite.** Дважды щёлкните по локальному файлу базы в Treemacs. Файл распознаётся по заголовку SQLite, поэтому подходят и базы без расширения. Повторное открытие той же базы возвращает в её SQL-консоль.

Слева находятся вкладки **Файлы** и **Объекты базы**, в центре — SQL-консоль, снизу — результаты. Навигатор показывает таблицы и представления по схемам. Для SQLite отображаются объекты основной базы `main`.

| Действие | Как выполнить |
| --- | --- |
| Посмотреть первые 100 строк | Щёлкнуть по таблице или представлению либо нажать `RET` |
| Посмотреть колонки и типы | Нажать `d` на объекте |
| Обновить объекты | Нажать `g` в навигаторе |
| Выполнить SQL | ПКМ в редакторе → **Выполнить выделение** или **Выполнить весь SQL** |
| Отсортировать результат | Щёлкнуть по заголовку колонки |
| Открыть запись вертикально | ПКМ на строке → **Просмотреть запись вертикально** |
| Вернуться к дереву файлов | Щёлкнуть **Файлы** в боковой панели |
| Закрыть рабочее пространство | **Работа → Clutch → Выйти из рабочего пространства Clutch** |

## Работа в файле `.sql`

Откройте **Работа → SQL → Работать через Clutch…** и выберите подключение. Запросы выполняются из текущего файла, результаты появляются под ним. В том же меню можно подключить файл после отмены выбора, сменить подключение или отключиться.

**Вернуться в обычный SQL-режим** отключает Clutch и сохраняет текст, выделение, кодировку и признак несохранённых изменений. Для текстовой консоли PostgreSQL выберите **Работа → SQL → Открыть iSQL…** и нужное подключение. iSQL использует `psql`.

## Регистр ключевых слов

`sqlup-mode` включается автоматически в SQL-буферах и Clutch. При наборе `select` превращается в `SELECT` после пробела или другого разделителя. Для готового текста используйте `M-x sqlup-capitalize-keywords-in-region` для выделения или `M-x sqlup-capitalize-keywords-in-buffer` для всего буфера.

## Файлы настройки

- [init-sql.el](lisp/init-sql.el) — SQLi, `sqlup-mode` и контекстные меню.
- [init-clutch-workspace.el](lisp/init-clutch-workspace.el) — навигатор базы, SQL-консоль и панель результатов.
- [init-treemacs.el](lisp/init-treemacs.el) — распознавание SQLite при двойном клике.
- [init-workspace-menu.el](lisp/init-workspace-menu.el) — меню **Работа**.
- `sql-connections.el` — личные подключения. Этот необязательный файл может содержать пароли и хранится вне Git.
