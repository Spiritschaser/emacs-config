# Конфигурация GNU Emacs

Графическая среда для работы с проектами, Python, SQL, Dart и Org. Конфигурация проверена на Windows. Текущая сборка сообщает `emacs-version` как `32.0.50`. Точка входа — [init.el](init.el), настройки по темам — в [lisp/](lisp/). Недостающие Lisp-пакеты устанавливаются при запуске. Внешние программы и настройки для нового компьютера перечислены в [INSTALL.md](INSTALL.md).

## Повседневная работа

| Действие | Клавиши |
| --- | --- |
| Выполнить команду | `M-x` |
| Открыть файл | `C-x C-f` |
| Сохранить файл | `C-s` или `C-x C-s` |
| Искать в буфере | `C-f` |
| Переключить буфер или окно | `C-x b` или `C-x o` соответственно |
| Открыть или скрыть Treemacs | `C-c t` |
| Перейти в Treemacs | `M-0` |
| Показать или скрыть структуру файла | `C-c o` |
| Узнать команду по клавише | `C-h k` |

`C` означает Ctrl, `M` — Alt. Evil добавляет режимы Vim, CUA — привычные сочетания для выделения и буфера обмена. Двойной клик по вкладке разворачивает окно, повторный восстанавливает раскладку. Desktop сохраняет буферы и окна между запусками и восстанавливает открытые Treemacs, Imenu и сеансы Codex, когда доступны их сохранённые данные.

## Рабочие пространства

- **Проекты.** Treemacs показывает дерево файлов, Imenu — функции, классы и другие элементы текущего файла. В SQL можно добавить раздел строкой `-- outline: Название`.
- **Python.** Tree-sitter, Eglot с BasedPyright, Ruff и Corfu помогают редактировать код. **Работа → Python Workspace** запускает IPython для ячеек `# %%`, выделения и целого буфера. [Руководство по Python](PYTHON-WORKSPACE.md)
- **SQL.** **Работа → Clutch** открывает сохранённое подключение. Двойной клик по локальной SQLite-базе в Treemacs открывает те же панели объектов, SQL и результатов. `sqlup-mode` переводит ключевые слова в верхний регистр. Для текстовой консоли PostgreSQL есть iSQL. [Руководство по SQL](SQL-WORKFLOW.md)
- **Dart / Flutter.** Eglot использует сервер Dart. Меню **Работа → Dart / Flutter** содержит команды запуска, перезагрузки и остановки Flutter Web.
- **Org.** Заметки с изображениями, вложениями, рисунками, картами мыслей и блоками Babel. [Руководство по Org](ORG-WORKSPACE.md) · [Демонстрация](org-workspace-demo.org)
- **Codex.** **Работа → Запустить Codex IDE** открывает нативную сессию в Emacs. Через MCP агент может получать сведения о буферах, окнах и выделении. [Диагностика моста](EMACS-SERVER.md) · [Обновление локального патча](patches/README.md)

История настройки и ссылки на подробности — в [PROJECT-NOTES.md](PROJECT-NOTES.md).
