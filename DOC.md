# GNU Emacs 31.1 — краткое руководство пользователя

**Платформа:** Windows 11, конфигурация подготовлена к переносу на Linux.

Emacs настроен как графическая среда для работы с Python, SQL и проектными файлами. Основные возможности доступны через вкладки, мышь, контекстные меню и стандартные команды Emacs.

## 1. Основные клавиши

В обозначениях Emacs: `C` — Ctrl, `M` — Alt.

| Действие                  | Команда   |
|---------------------------|-----------|
| Выполнить команду         | `M-x`     |
| Открыть файл              | `C-x C-f` |
| Сохранить файл            | `C-x C-s` |
| Переключить буфер         | `C-x b`   |
| Закрыть текущий буфер     | `C-x k`   |
| Перейти в другое окно     | `C-x o`   |
| Закрыть текущее окно      | `C-x 0`   |
| Развернуть текущее окно   | `C-x 1`   |
| Отменить текущую операцию | `C-g`     |
| Справка по клавише        | `C-h k`   |
| Справка по команде        | `C-h f`   |

Дополнительно настроены привычные Windows-сочетания клавиш и Evil (режим управления в стиле Vim).

## 2. Окна и вкладки

В каждом окне Emacs собственная строка вкладок.

**Одинарный щелчок по вкладке** — переключение буфера.

**Двойной щелчок по вкладке** — разворачивание окна на всю рабочую область. Повторный двойной щелчок восстанавливает прежнее расположение окон.

**Крестик на вкладке:**
- Если вкладок несколько — закрывает буфер, оставляя окно.
- Если вкладка последняя — закрывает буфер и окно.
- Последнее окно Emacs не закрывается.

Если один буфер открыт в нескольких окнах, закрытие через крестик уничтожает его во всех окнах. При несохранённых изменениях Emacs запрашивает подтверждение.

Расположение окон можно сохранить вручную:

| Действие               | Клавиши     |
|------------------------|-------------|
| Сохранить раскладку    | `C-x r w c` |
| Восстановить раскладку | `C-x r j c` |

Регистр `c` хранит раскладку только в текущем сеансе.

## 3. Treemacs — дерево файлов

Treemacs отображает каталоги и проекты в боковой панели.

- `Alt+0` — управление видимостью Treemacs.
- `TAB` — раскрытие и сворачивание каталогов.
- `RET` — открытие выбранного файла.
- Через контекстное меню доступны операции с файлами.

Treemacs может содержать несколько корневых каталогов. Автоматическое следование за текущим файлом отключено.

## 4. Python

При открытии `.py` используется `python-ts-mode`.

Работают:

- **Tree-sitter** — синтаксический анализ и подсветка.
- **Eglot + BasedPyright** — языковой сервер, диагностика и навигация по коду.
- **Ruff / Flymake** — проверка качества кода.
- **Corfu** — всплывающие предложения автодополнения.

Автодополнение появляется при работе с кодом. Для навигации и диагностики можно использовать команды Eglot через `M-x`.

## 5. SQL — два способа работы

### SQLi — классическая SQL-консоль

Используется для PostgreSQL через `psql`.

В `.sql` можно выделить запрос, открыть контекстное меню ПКМ и отправить выделение в SQLi. Также поддерживается выполнение всего буфера.

В контекстном меню есть подменю **«Подключиться к БД»**.

SQLi отображает результаты в текстовом виде.

### Clutch — интерактивный SQL-клиент

Clutch удобен для исследования данных, табличного просмотра и отдельных записей.

**Подключение:**

1. `M-x clutch-connect`.
2. Выбрать `ra1` (если подключение единственное, оно может выбираться автоматически).
3. `M-x clutch-query-console`.
4. При необходимости нажать `TAB` для отображения списка подключений.
5. Выбрать `ra1`.

Откроется SQL-консоль `*clutch: ra1*`.

### Контекстное меню SQL-консоли

ПКМ в области SQL:

| Пункт                | Действие                            |
|----------------------|-------------------------------------|
| Выполнить выделение  | Выполнить выделенный SQL            |
| Выполнить весь SQL   | Выполнить содержимое буфера         |
| Выбрать подключение… | Подключиться к серверу              |
| Переключить схему…   | Выбрать схему PostgreSQL            |
| Показать объекты БД… | Просмотреть таблицы и представления |

Выбор таблицы через «Показать объекты БД…» позволяет сформировать SQL-запрос.

### Таблица результатов Clutch

После выполнения SELECT результат открывается в интерактивной таблице.

- Щелчок по заголовку столбца — сортировка.
- ПКМ по записи → **«Просмотреть запись вертикально»** — открыть Record View.

### Вертикальный просмотр записи

Record View показывает одну строку в виде списка:

| Поле    | Значение |
|---------|----------|
| id      | 12345    |
| country | UZ       |
| browser | Chrome   |

ПКМ в Record View:

- **Следующая запись** — перейти к следующей строке результата.
- **Предыдущая запись** — вернуться к предыдущей строке.

Для закрытия окна используется `C-x 0`. Для уничтожения буфера — `C-x k` или крестик вкладки.

Важно: для открытия записи используется `clutch-result-open-record`, а не `clutch-record-mode`.

## 6. Контекстные меню

ПКМ открывает стандартное контекстное меню Emacs, дополненное командами текущего режима.

Меню SQL-консоли, таблицы результатов и вертикального просмотра Clutch различаются.

Если нужного действия нет в меню, его можно найти через `M-x`.

## 7. Настройка Emacs

Основной файл:

`~/.emacs.d/init.el`

Модули конфигурации:

`~/.emacs.d/lisp/`

Основные файлы:

| Файл                 | Назначение                            |
|----------------------|---------------------------------------|
| `init-ui.el`         | Интерфейс, вкладки, управление окнами |
| `init-toolbar.el`    | Панель инструментов                   |
| `init-treemacs.el`   | Дерево файлов                         |
| `init-python.el`     | Python                                |
| `init-lsp.el`        | Eglot                                 |
| `init-completion.el` | Автодополнение                        |
| `init-sql.el`        | SQLi, Clutch, контекстные меню        |
| `init-evil.el`       | Evil                                  |
| `init-keys.el`       | Сочетания клавиш                      |

**Применение изменений без перезапуска:**

Открыть изменённый `.el` и выполнить `M-x eval-buffer`.

Подключения и пароли PostgreSQL находятся в `~/.emacs.d/sql-connections.el`. Не публиковать этот файл и не передавать его AI-агентам.

## 8. Что пока не настроено

- Полноценная Outline-панель структуры кода.
- Jupyter и интерактивный просмотр результатов Python.
- Интеграция Codex с нативным интерфейсом Emacs.
- Фильтрация Clutch через ПКМ по значению ячейки.
- Независимые вкладки результатов SQL.
- ClickHouse и SQLite.

Все перечисленные функции планируются отдельно. Текущая конфигурация уже пригодна для повседневной работы с Python, PostgreSQL и проектными файлами.
